OpenMAIC 产品定位与端到端业务链路

发表于2026-11-11|更新于2026-11-11|AI辅助开发智能体应用
|浏览量:
项目/OpenMAIC/核心知识
OpenMAIC项目概览进阶

一句话：OpenMAIC（Open Multi-Agent Interactive Classroom，MIT）把「一个主题 / 一份文档」在几分钟内
转成可回放的互动课堂——AI 教师与 AI 同学讲解、白板推演、随堂测验、交互模拟、PBL 项目，
并导出成幻灯片、离线网页与成片视频。面向自学者、教师、企业内训；也可通过 skills/openmaic/
在 Agent 工作台内生成。

两条必须分清的「业务」

上游产品 本机 fork 的业务
卖什么 开源软件本身 ① 课件/微课成品 ② 帮客户把这套环境装通
用户 使用者、教师、二开者 闲鱼买家
产物 Stage 课堂 + 导出文件 编号交付包 + 云盘链接
口径在哪 README.md .workbuddy/xianyu-kejian/、xianyu-deploy/

混用这两套口径是最常见的事故来源，详见 [[12-business-line-and-tier-mapping]] 与 [[15-source-of-truth-and-layering-rules]]。

端到端旅程（上游事实）

步 用户动作 代码位置 产出实体
1 输入课题 / 上传材料 app/page.tsx、app/api/materials/** 素材（owner 隔离）
2 提交生成 app/api/generate-classroom/route.ts 异步 job（= generation run）
3 大纲 → 场景内容 → 交互动作 → 旁白 lib/server/generation/run/**、packages/@openmaic/generation/ Stage 文档
4 回放、讨论、白板、答题 app/classroom/[id]/、components/stage/、lib/playback/、lib/action/、app/api/chat/pi/ 运行时状态
5 导出 lib/export/、app/api/export-video/**、render-service/ PPTX / HTML / MP4 / .maic.zip
6 打包交付（fork 私有） lib/export/delivery-bundle.ts、lib/server/deliver/** 编号交付包
7 上云 + 通知（fork 私有） deploy/deliver-sidecar/、/api/deliver/upload 云盘目录链接 + 飞书卡片

第 2–3 步的契约见 [[03-classroom-pipeline-and-async-task-contract]]；第 5–7 步的实现见 [[07-export-capability-matrix-and-delivery-package]]
与 [[10-video-rendering-and-cloud-delivery]]。

三个容易被误解的边界

  1. 「课堂」不是一段视频：Stage 是结构化文档 + 动作序列，视频是后来渲染出来的派生品；
    参赛档甚至故意不给视频（见 [[13-delivery-package-spec]]）。
  2. 生成管线在服务端，成片有两条落点：run 由 PG + lease worker 驱动；浏览器交付包链路把
    MP4 存进 IndexedDB renderedVideos，自动上云链路由服务端 worker 从 render-service 下载到
    dataRoot。两条链路别混成一条，见 [[10-video-rendering-and-cloud-delivery]]。
  3. 导出 ≠ 交付：产品导出的是零散文件（deck、讲稿、字幕、页面），交付包是按 SKU 重新编号、
    补齐格式件后的另一层组装（delivery-bundle.ts 注释明确说它是 bench/pack-delivery.py 的浏览器等价物）。

上游文档没写、只能从代码读出的业务事实

  • /api/generate-classroom 只接受 { requirement, materialIds? }，pdfContent 被显式拒绝，
    outlineReview 强制 auto——「可选能力」不随请求走，由服务端配置决定。
  • 图片/视频生成失败、无旁白语音不会令整单失败，只进 result.warning。
  • 成片视频的交付路径与 PPTX/HTML 不同：自动上云链路由服务端 worker 按 render job 取回 MP4
    并写入 dataRoot 后上云；后者由浏览器 POST /api/deliver/upload（raw body）。

来源与可信度

README.md / README-zh.md（产品定位）、app/api/generate-classroom/route.ts（请求契约，已抽查）、
lib/export/delivery-bundle.ts:28-38（SKU 语义，已抽查）、packages/@openmaic/dsl/（实体名）。
其中「云盘 + 飞书」属 fork 私有能力，上游 README 零覆盖，见 [[10-video-rendering-and-cloud-delivery]]。
