drogon-pay 部署流水线

发表于2026-11-12|更新于2026-11-12|云原生运维容器化
|浏览量:
项目/drogon-pay/部署运维
drogon-pay数据与运维进阶
**Referenced Files** - deploy.yml - deployment_guide.md

触发与目标

deploy.yml（v* tag / workflow_dispatch）：Docker Hub 镜像 + AWS ECS（us-east-1，payserver-staging / payserver-production 集群）。staging 随 master、production 随 tag。

关键机制

  • preflight 灰跳：secrets 缺失时条件化跳过而非红失败（DOCKER_USERNAME/DOCKER_PASSWORD 等是强依赖）；
  • tag-gate 前置：与 release 共用 _tag-gate.yml，未认证 tag 到不了镜像推送与 ECS roll；
  • 生产安全网：先 RDS 快照、熔断回滚配置、/readyz 30 次健康检查、失败回滚旧 task-definition。

所需 secrets

Docker Hub（DOCKER_USERNAME / DOCKER_PASSWORD）、AWS 凭据、ECS 集群/任务定义参数、RDS 连接等，完整清单见 deployment_guide 与 AGENTS.md 部署节。本地对应资产在 examples/pay-server/deploy/（Prometheus/告警/Grafana/运维脚本）。

已知遗留

deploy.yml:11 的 ECR_REPOSITORY 环境变量未被任何步骤引用——实际推送目标是 Docker Hub，属可清理的遗留配置（已列入深度分析风险清单）。
